# 版本更新记录

> **记录规则：只有作者明确要求"记录到本文档"时，才允许新增/修改条目。**
> 未明确指示时，任何改动一律不得写入本文档（包括 bug 修复、机制调整、临时诊断、内部重构等）。

> **版本号规则（按变更级别递增，不按打包发布）：**
> - **系统级**（跨模块/框架级改动）→ 第一位 +1，后两位归零（如 0.0.x → 1.0.0）；
> - **模块级**（新增模块或成体系功能）→ 第二位 +1，第三位归零（如 0.0.1 → 0.1.0）；
> - **修改级**（bug 修复、小调整）→ 第三位 +1（如 0.0.1 → 0.0.2）；
> - **模组版本号与本文档同步**：每次版本号变动时，同步更新 `gradle.properties` 的 `mod_version` 与 `docs/INDEX.md` 顶部的版本行。
> - **记录提交编号**：仅在「发布新版本」时，于版本章节下记录发布时 HEAD 的短哈希（`> 提交: <短哈希>`），供下一版本确定变更范围；仅「更新版本」时不记录。
